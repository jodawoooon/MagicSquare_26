# MagicSquare Golden Master 회귀 안전장치 Interactive Prompt Transcript

## 사용 목적

이 문서는 **Golden Master 기준 파일 생성(GM-1)**, **Golden Master 테스트 코드(GM-2)**, **README 업데이트(GM-3)**, **Report/Transcript export**까지 진행된 세션의 요청/응답을 **대화형 프롬프트 transcript**로 정리한 export다.  
필요 시 각 `USER` 블록을 순서대로 재입력해 동일한 작업 흐름을 재현할 수 있다.

> **폴더 명칭:** 프로젝트 convention은 `Prompt/` (사용자 요청 «Prompting»과 동일 목적).
