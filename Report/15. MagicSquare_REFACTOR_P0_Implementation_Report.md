### 4.2 ECB 정렬 (Report/14 §7 P0-3, P0-4)

**목표 흐름 (구현 후):**

```text
boundary/screen/main_window.py
    ↓
boundary/screen/presenter.py
    ↓
boundary/ui_boundary.py
    ↓
boundary/pipeline.py
    ↓
control/solve_partial.py
    ↓
entity/solver.py
```

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| Pipeline 위치 | `control/pipeline.py` (control→boundary import) | `boundary/pipeline.py` |
| Golden Master import | `control.pipeline` | `boundary.pipeline` |
| Screen | `presenter` → `control.resolver` | `presenter` → `UIBoundary` only |
| input_validator | `from entity.constants` | `from boundary.constants` |
| Domain 예외 경계 | pipeline이 `UnsolvableDomainError` 직접 처리 | `solve_partial`이 `NoValidAssignmentError`로 변환 |

**신규·확장 파일:**

- `boundary/constants.py` — `GRID_SIZE`, `BLANK_VALUE`, `EXPECTED_BLANK_COUNT`, `INVALID_SIZE_*`
- `boundary/error_messages.py` — GUI용 code→message 매핑
- `boundary/pipeline.py` — `MagicSquarePipeline`, `SolveOutcome`
- `boundary/ui_boundary.py` — `validate` / `solve` (size + pipeline 위임)

**삭제:** `control/pipeline.py` (re-export 제거, import 경로 일원화)
