## 4) 코드 리뷰 요약 (Step 2 — High 스멜)

### 4.1 심각도별 이슈

| 심각도 | 이슈 | 위치 |
|---|---|---|
| **Critical** | boundary→entity 직접 의존 | `boundary/input_validator.py` L3–7 |
| **Critical** | GUI 풀이 경로 ≠ Pipeline 경로 (E002~E005 우회) | `presenter.py` vs `pipeline.py` |
| **High** | `NotImplementedError` 제어 흐름 | `boundary/validator.py`, `pipeline.py`, `presenter.py` |
| **High** | 오류 DTO·코드 중복 (`ErrorResponse`/`ResolveError`, `INVALID_SIZE`) | boundary + control |
| **High** | 테스트 collection ERROR 4건 | tests/boundary, tests/entity |
| **Medium** | `list[int]` primitive obsession (int[6]) | solver, presenter, contract |
| **Medium** | 상수 SSOT 분산 (`GRID_SIZE` 3곳) | entity/boundary/screen |
| **Medium** | `InputValidator` 부분 구현·E002/E005 코드명 불일치 | boundary |
| **Low** | `copy.deepcopy` for 4×4 | `entity/solver.py` |
| **Low** | `entity/user.py` 도메인 무관 | entity |

### 4.2 코드 스멜 ↔ 대응 기법

| 코드 스멜 | 대응 기법 |
|---|---|
| Illegal Dependency (boundary→entity) | Move Method, Dependency Inversion |
| Divergent Change (GUI vs Pipeline) | Facade, Strangler Fig |
| Shotgun Surgery (오류 코드 분산) | Extract Constant, Shared Kernel |
| Exception as Flow Control | Replace Exception with Result Type |
| Primitive Obsession | Replace Primitive with Value Object |
| Duplicate Code | Extract Method, Protocol |
