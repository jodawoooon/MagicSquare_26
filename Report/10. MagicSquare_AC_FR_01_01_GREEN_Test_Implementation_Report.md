## 4) 구현 요약

### 4.1 BoundaryValidator

- `grid is None` → `INVALID_SIZE`
- `grid = []` → 행 수 ≠ 4 → `INVALID_SIZE`
- `grid = [[]] * 4` → 열 길이 ≠ 4 → `INVALID_SIZE`
- 3×4 행렬 → `INVALID_SIZE`
- 유효 4×4 입력 → `NotImplementedError` (AC-FR-01-01 범위 외 — 정상 경로 미구현)

### 4.2 MagicSquareResolver (ECB 준수)

- `control → entity` 의존만 허용 — **`boundary` import 금지**
- `grid is None` 또는 크기 위반 시 `ResolveError(code, message)` 반환
- `MagicSquareSolver.resolve()` **0회** (mock/spy 검증 통과)
- 크기 통과 시 `solver.resolve(grid)` 위임 (스텁은 `NotImplementedError`)
