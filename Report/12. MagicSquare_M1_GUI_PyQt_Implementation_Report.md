## 4) 구현 상세

### 4.1 ECB 의존 방향

```text
boundary/screen/main_window.py   ← PyQt6 View (위젯·이벤트·표시만)
    ↓
boundary/screen/presenter.py   ← BoundaryValidator + MagicSquareResolver 호출
    ↓                    ↓
boundary/validator.py   control/resolver.py
                              ↓
                        entity/solver.py (control/factory.py 경유)
```

| 규칙 | 준수 |
|---|---|
| `screen` → `entity` 직접 import 금지 | ✅ `presenter`는 `control.factory`만 사용 |
| `control`/`entity`에 PyQt import 금지 | ✅ PyQt6는 `boundary/screen/`에만 |
| 비즈니스 로직 GUI 복제 금지 | ✅ `BoundaryValidator.validate()` SSOT 호출 |

### 4.2 ScreenPresenter

| 메서드 | 동작 | 백엔드 |
|---|---|---|
| `validate(grid)` | `ErrorResponse` 또는 `ValidationSuccess` 반환 | `BoundaryValidator` — 유효 4×4 시 `NotImplementedError` → 성공으로 매핑 |
| `solve(grid)` | `ResolveError` / `SolveSuccess` / `NotImplementedResult` | `MagicSquareResolver` — solver 스텁 시 `NotImplementedResult` |

### 4.3 MainWindow UI 구성

| 영역 | 구성 요소 |
|---|---|
| **입력** | 4×4 `QSpinBox` (0~16, 0=빈칸) |
| **샘플** | G0(완성), G1(small-first), G2(reverse), 빈 격자 — Report/06 §5 SSOT |
| **버튼** | 크기 검증 · 풀이 · 초기화 |
| **검증 시나리오** | 현재 격자 / null / `[]` / 3×4 — INVALID_SIZE 데모 |
| **결과** | 상태 라벨 · 상세 `QTextEdit` · 풀이 후 4×4 격자 미리보기 |

### 4.4 control/factory.py

GUI 레이어가 `MagicSquareSolver`를 직접 생성하지 않도록 Control 팩토리 제공:

```python
def create_magic_square_resolver() -> MagicSquareResolver:
    return MagicSquareResolver(solver=MagicSquareSolver())
```

`entity` import는 **control** 레이어 내부에만 존재.
