## 5) 검증 결과 (RED 실행)

### 5.1 실행 명령

```bash
python -m pytest tests/boundary tests/control -v --tb=long
```

### 5.2 결과 요약

| 구분 | 건수 | 원인 |
|---|---|---|
| **ERROR** | 6 | `boundary_validator` fixture — `ModuleNotFoundError: No module named 'boundary'` |
| **FAILED** | 2 | `from control.resolver import ...` — `No module named 'control'` |
| **PASSED** | 1 | 범위 제한 메타 테스트 (프로덕션 import 없음) |
| **합계** | 9 collected | exit code 1 |

### 5.3 실패 분석 결론

- 실패는 **비즈니스 로직 버그가 아님** — RED 단계에서 프로덕션 패키지 미구현으로 인한 ImportError
- Assert(`INVALID_SIZE`, message, `resolve` 0회)는 **setup/import 단계에서 중단**되어 아직 미검증
- RED 목적(의도한 이유로 실패하는 테스트 확보)에는 **부합**
