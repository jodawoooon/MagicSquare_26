## 6) Approve 패턴 설계

### 6.1 캡처 전략

| 방식 | 채택 | 비고 |
|---|---|---|
| stdout capture | ❌ | 플랫폼·인코딩 변동 |
| **API Result DTO serialization** | ✅ | `MagicSquarePipeline` → `SolveOutcome` → 텍스트 블록 |

### 6.2 비교 흐름

```text
capture_all() / capture_scenario()
    → open(expected).read() vs actual
    → 일치: PASS
    → 불일치: unified diff (--- expected / +++ actual) 후 FAIL
    → 기준 없음 + auto_create: 현재 출력으로 생성
```

### 6.3 기준 파일 구조

```text
[normal_success]
Input:
<4×4 grid rows>
Output:
[r1, c1, n1, r2, c2, n2]

________________________________________
```

섹션 구분자: `________________________________________`

## 7) 구현 상세

### 7.1 ECB 의존 방향

```text
tests/golden_master/capture.py
    ↓
control/pipeline.py (MagicSquarePipeline)
    ↓                    ↓
boundary/input_validator.py   control/resolver.py → entity/solver.py
boundary/validator.py (size)
```

| 규칙 | 준수 |
|---|---|
